# KryptOS / LFS build order — the roadmap.
# Pin exact versions to the LFS_VERSION book; this is the SEQUENCE (it rarely
# changes between releases). We write + run a recipe per line, chapter by chapter.
# Order matters: each stage depends on the last.

## Stage 5 — system configuration (LFS ch9)
# /etc/fstab, hostname=kryptos, /etc/os-release (NAME="KryptOS"), network,
# console, locale, /etc/inittab (sysvinit), bootscripts.

## Stage 6 — kernel + bootloader (LFS ch10)
linux          # configure + build the kernel
grub           # install + grub.cfg with a "KryptOS" menu entry


## Stage 6b — first-ISO developer tools
# Required for a source-first distro with binary options. Built in chroot after
# the final base system: CA roots, curl, git, and a self-host build-tool check.

curl
git
